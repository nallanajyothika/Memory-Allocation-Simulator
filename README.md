# Memory Allocation Simulator

## Project Overview

The Memory Allocation Simulator is an Operating Systems
project that demonstrates how memory is allocated to
processes using different memory allocation algorithms.

## Objectives

- Understand dynamic memory allocation.
- Implement different allocation algorithms.
- Visualize allocated and free memory.
- Calculate memory utilization.
- Understand internal and external fragmentation.
- Compare the performance of allocation algorithms.

## Technologies Used

- HTML
- CSS
- JavaScript
- Visual Studio Code

## Allocation Algorithms

1. First Fit
2. Best Fit
3. Worst Fit
4. Next Fit

## Features

- User-defined memory blocks.
- User-defined process sizes.
- Dynamic memory allocation.
- Process deallocation.
- Merging of adjacent free blocks.
- Visual memory map.
- Memory utilization dashboard.
- Internal fragmentation calculation.
- External fragmentation indicator.
- Algorithm performance comparison.

## Project Files

- index.html: Website structure.
- style.css: Website styling.
- script.js: Main application logic.
- allocation.js: Allocation algorithms.
- memory.js: Memory management.
- fragmentation.js: Fragmentation calculations.
- comparison.js: Algorithm comparison.
- README.md: Project documentation.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select Open with Live Server.
5. Use the input fields to enter memory blocks and processes.
6. Select an allocation algorithm.
7. Click Run Allocation.
8. Click Compare Algorithms to compare all four algorithms.

## Conclusion

This project demonstrates memory allocation techniques
used in operating systems. It helps understand memory
management, fragmentation, utilization and the
differences between allocation algorithms.
